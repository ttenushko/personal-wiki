# Android Developers — официальный портал разработчика

> Официальный ресурс Google для разработчиков Android-приложений: документация, инструменты, примеры кода, руководства по качеству и распространению.

---

## Обзор

**Android Developers** (developer.android.com) — центральный хаб для создания приложений под Android. Предоставляет:
- IDE и SDK (Android Studio, эмуляторы, инструменты сборки)
- API‑справочники и руководства по разработке
- Образцы кода (Samples) для быстрого старта
- Рекомендации по качеству, дизайну и распространению через Google Play
- Новости платформы, релизы ОС и новые возможности (Jetpack Compose, Android XR, Health Connect и др.)

---

## Основные разделы

### 1. Инструменты и загрузки
| Элемент | Описание |
|---------|----------|
| **Android Studio** | Официальная IDE (последняя стабильная: *Quail 3 | 2026.1.3*). Доступна для Linux, macOS, Windows. |
| **SDK / NDK** | Библиотеки, системные образы, инструменты командной строки. |
| **Play Console** | Панель публикации, мониторинга и монетизации приложений. |

### 2. Актуальные темы (Featured)
- **Android XR** — инструменты и ресурсы для разработки XR-приложений (AR/VR).
- **Android 17 (API 37)** — исходный код в AOSP, обновление для Pixel, топ-5 изменений для подготовки приложений.
- **Jetpack Compose** — 5-летие декларативного UI-фреймворка, ставшего индустриальным стандартом.

### 3. Направления разработки (вертикали)
| Вертикаль | Фокус |
|-----------|-------|
| **Productivity apps** | Медиа, адаптивные макеты, многооконность. |
| **Social & messaging** | Пуши, пузыри уведомлений, расшаривание, профили пользователей. |
| **Camera & media** | CameraX, Media3, ExoPlayer, кодеки, HDR, многоустройственная экосистема. |
| **Health & fitness** | Health Services, Health Connect, сенсоры, фоновый мониторинг. |

### 4. Обучение и справочники
- **Developer guides** — пошаговые туториалы с переиспользуемыми сниппетами.
- **Sample code** — готовые проекты (GitHub / встроенные в Studio).
- **Quality guidelines** — Material Design, доступность, производительность, безопасность, тестирование.
- **Distribute your app** — публикация в Play, модульная доставка, A/B-тестирование, отчёты о сбоях.

## Лицензионное соглашение Android SDK (кратко)

Полный текст соглашения приведён на странице загрузки Android Studio. Ключевые пункты:

1. **Предмет лицензии** — SDK (системные файлы, упакованные API, Google APIs add-ons) выдаётся под лицензией Google.
2. **Цель использования** — только разработка приложений для *совместимых* реализаций Android (прошедших CTS).
3. **Ограничения** — нельзя использовать SDK для других платформ, создавать производные SDK, реверс-инжинирить, распространять SDK.
4. **Права на ваш код** — Google не претендует на IP приложений, созданных с SDK.
5. **Конфиденциальность** — сбор анонимной статистики использования инструментов (с согласия).
6. **Сторонние API/данные** — отвечаете за соблюдение их условий; Google не несет ответственности.
7. **Расторжение** — при нарушении, по требованию закона, прекращении партнёрств или коммерческой нецелесообразности.
8. **Отказ от гарантий** — SDK предоставляется «как есть» (AS IS).
9. **Ограничение ответственности** — Google не несёт ущерб (прямой, косвенный, случайный, تبعовый).
10. **Индемнификация** — вы защищаете Google от претензий, связанных с вашим использованием SDK / приложениями.
11. **Экспортный контроль** — соблюдение US export laws (ограничения по странам, лицам, назначению).
12. **Применимое право / юрисдикция** — закон штата Калифорния, суды округа Санта-Клара.

> ⚠️ При скачивании Android Studio вы должны явно принять эти условия.

## Ключевые моменты (Key Takeaways)

- **Единая точка входа** — всё необходимое для разработки, тестирования и публикации集中 в одном месте.
- **Свежесть** — страница отражает последние релизы (Android 17, Compose 5 лет, XR).
- **Вертикальная навигация** — быстрые входы в популярные домены (соцсети, медиа, здоровье, продуктивность).
- **Правовая ясность** — лицензия SDK отделена от условий Play Console и сторонних API.
- **Инструментарий «из коробки»** — Android Studio поставляется с эмулятором, профайлером, инспектором компоновки, поддержкой Compose Preview.
