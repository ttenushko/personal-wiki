# Замыкания и декораторы в Python

## Определение замыканий

Замыкание (closure) в Python — это функция, которая сохраняет ссылки на переменные из окружающей среды (области видимости), в которой она была определена. Замыкания позволяют функциям "запоминать" состояние и данные из внешней области, не вызывая их пересылку.

## Работа декораторов

Декораторы — это функции, которые модифицируют поведение других функций без изменения их кода. Они реализуются через обёртку функций и часто используются для добавления функциональности (логирование, аутентификация, обработка ошибок). Декораторы применяются через оператор `@decorator_name` в начале определения функции.

## Примеры

### Пример замыкания
```python
def outer():
    x = 10
    def inner():
        return x
    return inner

inner_func = outer()
print(inner_func())  # Вывод: 10
```

### Пример декаратора
```python
def debug(func):
    def wrapper():
        print(f"Вызов функции: {func.__name__}")
        return func()
    return wrapper

@debug
def greet():
    print("Приветствуем вас!")

greet()  # Вывод: Вызов функции: greet\nПриветствуем вас!
```

## Ключевые моменты

- Замыкания сохраняют доступ к переменным из области видимости родительской функции.
- Декораторы позволяют добавлять логику к функциям без модификации их кода.
- Декораторы используются для обработки аспектов программного обеспечения (логирование, аутентификация).
- Замыкания могут приводить к проблемам с утечкой памяти при неправильном использовании.
