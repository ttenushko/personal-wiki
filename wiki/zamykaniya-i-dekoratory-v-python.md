# Замыкания и декораторы в Python

## Определение замыкания

Замыкание (closure) в Python — это функция, которая сохраняет доступ к переменным из внешней области видимости (лексическое окружение), даже после того, как внешняя функция завершила выполнение.

## Что такое декоратор

Декоратор — это функция, которая принимает другую функцию в качестве аргумента и возвращает новую функцию. Он используется для добавления функциональности без изменения исходного кода функции. Декораторы применяются через синтаксис `@decorator_name` перед определением функции.

## Примеры

### Пример замыкания
```python
def outer():
    x = 10
    def inner():
        return x
    return inner

inner_func = outer()
print(inner_func())  # Вывод: 10
```

### Пример декоратора
```python
def debug(func):
    def wrapper():
        print(f"Вызов функции: {func.__name__}")
        return func()
    return wrapper

@debug
def greet():
    print("Привет, мир!")

greet()  # Вывод: Вызов функции: greet\nПривет, мир!
```

## Ключевые моменты

- Замыкания сохраняют доступ к переменным из внешней лексической области.
- Декораторы позволяют добавлять поведение к функциям без изменения их кода.
- Декораторы используются для логирования, кэширования и других сквозных задач.
- Замыкания могут использоваться для создания приватного состояния.
